Movement

Code installation

Using JavaScript code to track movement and generate live dynamic visuals with different sound depending on how the user moves. Collaboration between me and designer Ellen Karlsson.

Process

A camera captures your body and picks up keypoints from head to toe. The keypoints leave a trace of lines when you move to create a visual representation of the body, linking your movement to a digital expression.


We explored how to use the body as a tool for creating visuals, and how to make the experience fun and engaging for the user.


Tools: Visual Studio Code, p5js Web Editor, Ml5.js

Beatbox

Brief
